# Fold 7 runbook · V0.1

1. Open GitHub in the browser/app.
2. Open `packersmexico/packersmexico.github.io`.
3. Actions → `PMX Video Factory · Render`.
4. Tap `Run workflow`.
5. Select family + mode and paste the LOCKED fields from the 03/04 handoff.
6. Optional: paste a validated media URL for audio or visual asset.
7. Run.
8. When complete, download the `pmx-video-*` artifact.
9. 04 performs visual QA.
10. Only after 04 PASS does the piece return to 05.

A render is not publication authorization.
