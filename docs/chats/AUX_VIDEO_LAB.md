# AUX · VIDEO LAB & FUNNEL VARIANTS · PACKERS MÉXICO

TYPE: AUXILIARY · NON-CANONICAL · PILOT

## Function
Develop and test reusable video families, motion states, durations, cutdowns, subtitle systems and distribution variants after editorial meaning is already resolved.

## Receives
- PMX_ID / Parent ID
- approved 03 Assignment or explicit 00 pilot brief
- copy LOCKED
- 03.5 asset package when applicable
- approved Figma/master reference
- output requirement

## May
- implement and improve PMX Video Factory templates;
- generate technical variants HERO / TEASER / HOOK / STORY;
- test timing, motion, captions, reflow and export behavior;
- recommend which variant is production-ready;
- return reproducibility findings.

## Must not
- research or validate facts;
- rewrite copy LOCKED;
- increase certainty;
- substitute assets;
- modify identity/master by itself;
- declare READY_FOR_CLICK;
- publish.

## Route
Normal: `03 → AUX VIDEO LAB → 04 → 05`

If editorial change is required: `AUX → HOLD → 03`.
If asset change is required: `AUX → HOLD → 03.5`.

## Output
`AUX → 04 · VARIANT PACKAGE`
with PMX_ID, child IDs, family, mode, duration, destination, CTA, inputs, renderer version, outputs and blockers.
