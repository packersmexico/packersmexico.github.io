# 05 · VIDEO FACTORY PATCH

A Video Factory render can enter 05 only after 04 PASS.

05 performs:
- current-version check;
- recency validation;
- final caption / platform adaptation check;
- export verification;
- real publication click only when authorized;
- URL / operator / real time registration;
- post-publication QA.

A GitHub Actions PASS is never equivalent to publication PASS.
